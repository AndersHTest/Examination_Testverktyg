### User Story: Startsida
<pre>
Som en användare på Läslistan
vill jag att den första sidan som visas är katalogsidan
så att jag kan välja mina favoritböcker.
</pre>
* Surfa in på Läslistan
* Verifiera att katalogknappen är disabled.
* Verifiera att dom andra knapparna är enabled.
* Verifiera att du ser ett h2 element med texten "Välkommen!"
* Verifiera att du ser en paragraf med texten:
"Sidan för dig som gillar att läsa. Välj dina favoriter."


### User Story: Klicka på hjärtknappen flera gånger
<pre>
Som en användare på Läslistan
vill jag undersöka vad som händer om jag trycker på hjärtknappen flera gånger
så att jag stillar min nyfikenhet
</pre>
* Surfa in på Läslistan
* klicka på hjärtknappen 1, 2 och 3 gånger
* verifiera att hjärtmarkeringen läggs till, tas bort och läggs till igen


### User Story: Lägg till favoritbok
<pre>
Som en användare på Läslistan
vill jag kunna lägga till mina favoritböcker 
så att jag lätt kan komma åt och se dom under "Mina böcker".
</pre>
* Surfa in på Läslistan
* Klicka på hjärtknappen till vänster om dina favoritböcker
* Klicka på knappen "Mina Böcker"
* Verifiera att dina favoritböcker listas här


### User Story: Lägg till ny bok
<pre>
Som en användare på Läslistan 
vill jag kunna lägga till en ny bok
så att jag kan se den i katalogen.
</pre>
* Surfa in på Läslistan
* Klicka på knappen "Lägg till bok"
* Fyll i titel och författare
* Klicka på knappen "Lägg till ny bok"
* Klicka på knappen "Katalog"
* Verifiera att boken finns listad i katalogen


### User Story: Statistik
<pre>
Som en användare på Läslistan
vill jag kunna se statistik över hur många böcker som finns och hur många som är favoritmarkerade
så att jag kan se hur många böcker som finns och hur många favoriter som favoritmarkerats.
</pre>

* Surfa in på Läslistan
* Klicka på knappen "Statistik"
* Verifiera att det visas hur många böcker som är tillgängliga i katalogen.
* Verifiera att du kan se hur många böcker som har favoritmarkerats.


### User Story: Statistik antal hjärtmarkerade böcker
<pre>
Som en användare på Läslistan
vill jag kunna se statistik på hjärtmarkerade böcker
så att jag kan se hur många böcker som har hjärtmarkerats totalt
</pre>
* Surfa in på Läslistan
* hjärtmarkera x antal böcker
* Klicka på statistik
* Verifiera att det är lika många hjärtmarkerade böcker i statistiken


### User Story: Statistik antal böcker i katalogen
<pre>

</pre>


### User Story: Navigering
<pre>
Som en användare på Läslistan
vill jag kunna navigera på hemsidan utan problem
så att jag enkelt kan se alla vyer
</pre>

* Surfa in på Läslistan

* Verifiera att du är på rätt vy med hjälp av elementen på sidan
